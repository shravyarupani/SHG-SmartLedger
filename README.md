# SHG SmartLedger
## Overview
A digital financial management platform for Self Help Groups (SHGs) to manage savings, loans, EMIs, meetings, and notifications transparently.

## Features
- Member dashboard
- Loan tracking
- EMI management
- Savings records
- Role-based access
- Admin/Leader/Member modules
- Notifications
- Database seeding

## Tech Stack
Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Django
- Python

Database:
- MySQL

Other Tools:
- Antigravity workflow integration

## Architecture
Built using Django MVT architecture with Server-Side Rendering (SSR).

## Database
MySQL relational database connected using PyMySQL.
